TRAKWAY: PANEL RUN — FLAT PWA v1.0

DEPLOY
1. Extract the ZIP.
2. Upload every file directly to the HTTPS site root.
3. index.html, game.js, styles.css, sw.js and manifest.webmanifest must remain siblings.
4. No build step, login, database or server-side code is required.
5. The game installs as a portrait PWA and caches locally for offline play.

GAME
- Retro/cartoon portrait arcade format.
- Installation unit reverses up-screen; cab faces down-screen.
- Rear-mounted lorry-loader crane is at the working/reversing end.
- 30-panel maximum game inventory.
- Move LEFT / RIGHT only at hardstanding/crossover opportunities.
- GRAB / LAY collects roadside panels or fills route gaps at the yellow work line.
- Crane actions automatically pause the moving map and show stabilisers/crane movement.
- Clean panels score; dirty panels deduct score and can add traction loss when laid/driven over.
- Missing panels cause impact, vehicle damage and traction loss.
- Unsuitable ground outside the planned route ends the run.
- GS6 event uses a simplified LOCK OFF game control. This is NOT a substitute for the real OHL procedure.
- Occupied work zone: wait. Operating the clamp ends the run.
- Taco Break checkpoints show short safety-awareness prompts.
- The SHIFT CLOCK accelerates as difficulty rises instead of showing a speedometer.

SAFETY
This is a stylised game and awareness aid. Speeds, timing, distances, crane movements and game controls do not represent real Trakway operations. Do not reproduce gameplay actions on site. Real work must follow the current job pack, approved method statement, DRA, training, site controls and Responsible Person instructions.

REFERENCE BASIS
The truck/handling concept was based on the uploaded Sunbelt Rentals Trakway Method Statement / Lift Plan material, including vehicle-mounted lorry-loader controls, rear working end, stabiliser/ground-control concepts, clamp handling, test-lift awareness, exclusion-zone awareness and crane stowing principles. The game intentionally simplifies these into arcade mechanics.
